# Dominion Fall: play in your browser

**Play:** https://aryananandjha.github.io/Dominion-Fall-Playable/

This repository holds only the web build of *Dominion Fall*, a third-person
game where every enemy thinks for itself, a hive mind gives them orders, and
the colony learns how you fight. Made by Aryan Anand Jha.

- Desktop Chrome, Edge or Firefox; the first load takes about 20–30 seconds.
- Move with WASD and the mouse, aim with the right mouse button, fire with the
  left. Shift sprints (tap to roll), C slides, Esc pauses; K on the pause
  screen rebinds any key.
